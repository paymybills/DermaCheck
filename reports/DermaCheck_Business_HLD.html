How DermaCheck works

A plain-language system map for business partners

Think of it as a digital front desk for skin concerns. It gathers the right details, helps a person understand what may need attention, and points them toward care. A clinician still makes the medical decision.

The journey today

01 · PERSON

Describes the concern

Enters symptoms, body area, duration and city. A skin photo is optional.

›
02 · WEBSITE

Collects the details

The mobile-friendly page checks the form and sends it to the server.

›
03 · SERVER

Coordinates the request

Checks file and text limits, then asks an external AI service to review the information.

›
04 · AI + SEARCH

Returns two kinds of help

Possible explanations and warning flags; search-backed local clinic suggestions.

›
05 · PERSON

Chooses the next step

Reads the screening summary and contacts a qualified clinician if needed.

Who runs which part?

Vercel hosts the website and API. Google's Gemini API processes the screening request; Google Search grounding supports care suggestions. A dermatologist would provide diagnosis and treatment in a separate consultation.

What is live—and what is not?

Live: guided intake, optional photo, AI-assisted summary, alerts and clinic suggestions. There is no doctor review, appointment booking, verified provider directory or patient-record system in the current prototype.

Before a real service launch

  • Have clinicians validate safety and review high-risk cases.
  • Verify clinic listings and add a clear consent/privacy flow.
  • Add rate limits, monitoring and a plan for API outages.
